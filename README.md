# КассаРадар

Прогноз кассовых разрывов ИП и микробизнеса на 14 дней и готовое предложение банка.
Прототип для хакатона «Финтех без границ», спринт №1. **Все данные синтетические.**

## Запуск
```bash
pip install numpy pandas pytest
python generate_data.py 600     # синтетические операции -> transactions_synthetic.csv
python evaluate.py              # скользящий бэктест (около 3 минут) -> eval_rows.csv
python metrics.py               # метрики на тестовых клиентах -> metrics.json
python economics.py             # сценарии и чувствительность -> economics.json, sensitivity.json
python build_demo.py            # демо -> demo.html (открыть в браузере)
python -m pytest -q             # автотесты
```

## Состав
- `generate_data.py` — генератор операций по счетам ИП (розница, услуги, B2B, интернет-торговля)
- `model.py` — прогноз остатка (блочный бутстрап + регулярные платежи), вероятность разрыва, подбор лимита
- `evaluate.py`, `metrics.py` — бэктест и метрики против наивного метода
- `economics.py` — финансовая модель (допущения явно указаны в коде)
- `build_demo.py`, `demo_template.html` — интерактивное демо
- `test_model.py` — тесты

## Ограничения
Метрики получены на синтетических данных; в тесте 68 реальных разрывов. Модель не использует нейросети и
рассчитана на работу внутри контура банка (on-prem).
